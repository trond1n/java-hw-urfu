# Учет студентов - консольное приложение на Java

Итоговое домашнее задание по дисциплине «Специализированные инструменты прикладного программирования» (УрФУ, 1 семестр).

Программа хранит список студентов, позволяет добавлять их вручную или из CSV-файла, проверяет корректность данных, обрабатывает список через Stream API и сортирует его собственными алгоритмами.

## Выполненные уровни

| Уровень | Что сделано |
|---|---|
| 1. Базовый | Класс `Student`, консольное меню в цикле, ввод вручную и из файла, валидация, обработка исключений, try-with-resources, Stream API (filter, map, sorted) |
| 2. Собственная коллекция | `MyArrayList<T>` - аналог `ArrayList` с автоматическим расширением массива; используется в репозитории вместо стандартного `List` |
| 3. Сортировки и полиморфизм | Интерфейс `SortAlgorithm<T>`, реализации `BubbleSort` и `InsertionSort`; выбор алгоритма, поля и направления сортировки в меню |

## Требования

- Java 17 или новее

## Запуск

### IntelliJ IDEA

1. Открыть папку проекта.
2. Правый клик по папке `src` → **Mark Directory as** → **Sources Root** (если она не подсвечена синим).
3. **File** → **Project Structure** → **Project** → выбрать **SDK** версии 17 или новее.
4. Запустить `src/app/Main.java`.

Рабочая папка должна быть корнем проекта - тогда файл по умолчанию `data/students.csv` найдется.

### Командная строка

Из корня проекта:

```bash
javac -encoding UTF-8 -d out $(find src -name "*.java")
java -cp out app.Main
```

В PowerShell:

```powershell
javac -encoding UTF-8 -d out (Get-ChildItem -Recurse src -Filter *.java).FullName
java -cp out app.Main
```

Если в консоли Windows русский текст отображается неправильно, выполните перед запуском `chcp 65001`.

## Меню

```
===== МЕНЮ =====
1. Добавить данные вручную
2. Загрузить данные из файла
3. Обработать данные
4. Показать всех студентов
5. Удалить студента
6. Выбрать алгоритм сортировки
7. Показать студента по номеру
0. Выход
```

| Пункт | Что делает |
|---|---|
| 1 | Запрашивает имя, балл и номер зачетки; каждое поле проверяется сразу после ввода |
| 2 | Загружает студентов из CSV; Enter - файл по умолчанию `data/students.csv`. Некорректные строки пропускаются с указанием номера строки и причины |
| 3 | Запрашивает порог балла и выводит имена и баллы студентов не ниже порога, по убыванию балла (Stream API: `filter` → `sorted` → `map`) |
| 4 | Выводит всех студентов в порядке добавления (через `toString()` собственной коллекции) |
| 5 | Удаляет студента по номеру в списке |
| 6 | Сортирует список: выбор алгоритма (пузырьком / вставками), поля (балл / имя) и направления (по возрастанию / по убыванию). Исходный список не меняется |
| 7 | Показывает студента по номеру в списке |
| 0 | Завершает программу |

## Формат файла

CSV с разделителем `;` и строкой заголовка:

```
name;averageGrade;recordBookNumber
Иван Петров;4.5;100001
Мария Смирнова;4.9;100002
```

Балл можно писать через точку или запятую. В `data/students.csv` специально оставлены несколько некорректных строк, чтобы показать валидацию при загрузке.

## Правила валидации

| Поле | Правило |
|---|---|
| Имя | От 2 до 50 символов; одно или несколько слов с заглавной буквы, разделенных пробелом или дефисом (`Иван Петров`, `Анна-Мария Ли`) |
| Средний балл | Число от 0 до 5 |
| Номер зачетки | Ровно 6 цифр |

При ошибке выводится правило и введенное значение, например: `Номер зачетки - ровно 6 цифр, получено: "12"`.

## Обработка ошибок

- Нечисловой ввод в меню и в числовых полях - сообщение и повторный запрос.
- Несуществующий файл - `Файл не найден: <путь>`.
- Недопустимый путь (например, с символами `<>`) - `Некорректный путь к файлу: <путь>`.
- Неверный номер студента при удалении или поиске - `Нет студента с номером N.`
- Закрытие потока ввода (Ctrl+D / Ctrl+Z) - программа завершается без ошибки.
